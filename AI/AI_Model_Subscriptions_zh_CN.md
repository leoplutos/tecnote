# AI模型订阅

### OpenCode Go

OpenCode Go 是一项面向 AI 编程的 `低成本订阅服务`，首月 `$5`，之后 `$10/月`。

订阅后可以通过 OpenCode 访问多种热门的开源编程模型，例如 `GLM`、`Kimi`、`DeepSeek`、`Qwen`、`MiniMax`、`Grok` 等。

服务主要针对 `Coding Agent` 场景，适合日常代码生成、重构、调试和项目开发。

不同模型拥有不同的月度使用额度，额度用完后可以继续使用免费模型，或通过账户余额继续使用。

官方文档：[OpenCode Go](https://opencode.ai/docs/zh-cn/go)

## Command Code Go

Command Code Go 是一项面向 AI 编程的低成本订阅服务，提供多种主流 AI 编程模型的统一访问。

订阅后可以通过 Command Code 使用多种模型，适合 `Coding Agent`、代码生成、重构、调试和日常开发等场景。

相比单独购买各模型的 API，Command Code Go 更适合希望以固定月费使用多个 AI 编程模型的用户。

具体可用模型、使用额度和套餐价格会根据官方计划有所不同。

套餐说明：[Command Code Go](https://commandcode.ai/zh/pricing)
